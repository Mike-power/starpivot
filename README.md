# 星枢（StarPivot）· 星地协同智能体推理加速系统

> 在通信受限、星上算力受限的真实约束下，让卫星智能体"平时自己算（快、省），难事交给地面大模型（准、强）"。

## 这个项目同时服务四件事

| 线 | 作用 |
|----|------|
| 跳槽作品 | GitHub 开源系统，"卫星 + LLM Agent"题材稀缺，2027.2 底 v1.0 |
| AI Infra 副线 | 推理加速（量化 / 前缀缓存 / 投机解码）的真实落地场景，探 60-90 万档 |
| 博士课题 | 导师方向（AI 智能体）的细分落点，论文 + 专利 |
| 手艺积累 | 半年实打实的系统设计、仿真、压测经验 |

## 架构

```
┌─────────────────────────────────────────────┐
│ 星上侧（Jetson Orin 等效平台）                │
│   LoRA 蒸馏小模型(1.5-7B) + AWQ量化 + 投机解码 │
│   └─ 常规任务自主决策                          │
└──────────────┬──────────────────────────────┘
               │ 通信窗口 / 带宽受限（延迟注入模拟）
               ▼
┌─────────────────────────────────────────────┐
│ 地面侧（vLLM）                                │
│   32B 大模型 + 前缀缓存 + 工具调用投机执行      │
│   └─ 复杂规划与兜底                            │
└─────────────────────────────────────────────┘
```

## 创新点

1. ⭐ 通信窗口感知的星地分层推理调度方法（**专利主点**）
2. 星载受限算力下的大模型压缩与加速（**论文主点**：蒸馏 + 量化 + 投机解码组合拳）
3. Agent 多步工作流的前缀缓存复用（通用加速）

## 目录

- `docs/` — 项目提案、决策记录
- `sim/` — 星座任务仿真场景（观测规划 + 应急重规划）
- `edge/` — 星上侧：小模型推理、量化、投机解码
- `ground/` — 地面侧：vLLM 服务、前缀缓存
- `benchmark/` — 评测脚本与实验数据（三基线 × 四维度指标）

## 红线

- 只用公开数据（TLE、自建合成星座场景）与自有设备，**与工作项目彻底切割**
- 论文/专利若挂博士课题，归属学校，需与导师挑明
