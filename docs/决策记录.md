**背景**：跳槽冲刺计划需要一个同时覆盖 Agent + AI Infra、产出专利论文的旗舰项目。导师方向为 AI 智能体（未定细分），本人正在做卫星智能体（仿真与策略模拟）。

**决策**：
1. 选定方向 A（边缘 Agent 推理加速）并与卫星场景结合，项目定名「星枢」；
2. 不转硬件——"卖铲子"的最优解是软件铲子（推理框架/部署工具），硬件方向因技能清零与行业周期被否定；

4. 项目同时服务四线：跳槽作品 / Infra 副线 / 博士课题 / 手艺积累。

**红线**：公开数据 + 自有设备，与工作项目彻底切割（防职务发明争议）；论文专利挂博士课题需与导师挑明。
