# 文献扫描结论（2026.9.27，scholar 插件，4 组关键词 × 10 篇）

> 目的：为论文第 2 章相关工作提供素材，并验证"首个/首次"类表述是否成立。
> 原始数据：sat_llm.csv / sat_sched.csv / confidence.csv / sat_agent.csv（同目录）。

## 一、四个方向的文献版图

### 1. 卫星 + 大模型在轨/星地推理（sat_llm）
- **Y Shi et al., "Satellite edge artificial intelligence with large models", Science China Information Sciences, 2025（引用 30）**——卫星边缘大模型架构综述，LAM/LLM 星上推理架构与联邦微调，最权威的领域综述。
- **S Zhang et al., "Communication-Efficient Collaborative LLM Inference over LEO Satellite Networks", 2026**——LEO 网络中通信高效的协作 LLM 推理，**与本论文最接近的方向之一**（星地协作推理），但聚焦通信效率优化，未见置信度路由与窗口调度的联合设计。
- **Z Li et al., "Enabling Near-realtime Remote Sensing via Satellite–Ground Collaboration of Large VLMs", 2026**——大型视觉语言模型星地协同用于近实时遥感，场景相邻。
- **T Sandholm et al., "SkyMemory: LEO edge cache for transformer inference", 2026**——LEO 边缘缓存加速 transformer 推理。
- **D Xu et al., "Space-Native Hardware for On-Satellite LLM Inference", 2025**；**M Nevo et al., "Payload Operation Using On-Board Vision Language Model", 2025**——星上 VLM 载荷实操，证明星上部署 LLM 已工程可行。
- **H Sang et al., "Onboard deployment of remote sensing foundation models: review", Remote Sensing, 2026**——在轨基础模型部署全面综述（架构/优化/硬件）。

### 2. 星上边缘计算与窗口调度（sat_sched）
- **H Fan et al., "Dynamic digital twin and online scheduling for contact window resources", IEEE TII, 2022（引用 30）**——窗口资源数字孪生 + 在线调度，含优先级，窗口调度代表作。
- **Q Tang et al., "Joint service deployment and task scheduling for satellite edge computing", 2024（引用 147）**；**T Huang et al., dual-timescales, 2024（引用 41）**——服务部署 + 任务调度联合优化（两时间尺度）。
- **F Wang et al., "Time-sensitive scheduling … end-to-end collaborative latency tolerance", 2023（引用 59）**——时敏任务调度。
- **Y Liu et al., "Online computation offloading for collaborative space/aerial-aided edge computing", 2023（引用 115）**——计算卸载代表作。
- 共同点：调度对象是传统计算任务，**未涉及 LLM 推理任务的可分层性与置信度语义**。

### 3. 置信度路由与级联推理（confidence）
- **H Luo et al., "Toward edge general intelligence with Multi-LLM", IEEE, 2025（引用 103）**——多 LLM 边缘架构/信任/编排综述，confidence-based early exit 被点名为关键技术。
- **AP Behera et al., "Towards efficient multi-llm inference: routing and hierarchical techniques", 2025（引用 28）**——路由与级联技术表征分析。
- **Y Moslem & Kelleher, "Dynamic model routing and cascading for efficient LLM inference: A survey", 2026（引用 25）**——动态路由/级联综述。
- **S Kolawale et al., "Agreement-based cascading for efficient inference", 2024（引用 16）**——基于一致性的级联。
- **T Zhang et al., "Leveraging uncertainty estimation for efficient llm routing", 2025（引用 28）**——不确定性估计驱动路由。
- 共同点：路由/级联的升级通道被视为**带宽充裕的云/边 API**，无人讨论升级通道受物理过境窗口约束的情形。

### 4. 卫星智能体（sat_agent）
- **X Gao et al., "Agentic satellite-augmented … survey on generative approaches", IEEE COMST, 2026（引用 45）**——生成式智能体 + 卫星网络综述。
- **S Javaid et al., "Leveraging LLMs for integrated satellite-aerial-terrestrial networks", 2024（引用 93）**——LLM 使能空天地一体化网络综述。
- **W Sun et al., "SCNOC-agentic", 2025**；**H Cao et al., "Think-Do Architecture", IEEE Network, 2026**——网络运维智能体架构。
- 共同点：智能体做网络管控/编排，**非星上推理任务的路由与调度**。

## 二、"首个/首次"表述核验结论

| 候选表述 | 判定 |
|---|---|
| "首个星地协同 LLM 推理系统" | ❌ 不成立——协作推理（Zhang 2026）、VLM 星地协同（Li 2026）、边缘缓存（SkyMemory 2026）已有 |
| "首个将 LLM 置信度路由用于星地推理" | ⚠️ 需再查——edge-cloud 级联很多，但"星地 + 置信度"组合在 40 篇扫描内未见；建议投稿前补一轮精确检索 |
| **"首次将输出置信度路由与过境窗口排队调度联合设计，并基于真实 TLE 轨道开源评测"** | ✅ **成立**（本轮扫描内）——协作推理不管调度，窗口调度不认 LLM，置信度路由默认带宽充裕；三者交叉点为空 |
| "首个开源的星地协同推理评测框架" | ⚠️ 措辞需保留"评测框架/仿真契约"限定，避免与硬件实测类工作冲突 |

**建议论文定位句**（引言/贡献点使用）：
> 与已有星地协作 LLM 推理工作聚焦通信效率优化不同，本文首次将模型自评置信度引入星地任务路由，与过境窗口排队调度联合设计，并给出 τ-成功率-误收率-能效的多目标权衡规律；相关工作中，窗口调度未利用 LLM 任务的可分层性与置信度语义，置信度路由与级联推理则默认升级通道带宽充裕，未考虑物理过境窗口的稀缺性约束。
