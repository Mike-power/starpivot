# 表 1  算法在线开销逐项核算（n 队列长度，N 任务总量）

| 环节 | 复杂度 | 说明 |
| 置信度路由判定 | O(ℓ_on) | 与星上推理同开销，无额外算法代价 |
| 任务两路径延迟估计 | O(M) | M 为当日窗口数（实测 3–4），可视为 O(1) |
| 可行性检查（策略 b） | O(n) | 模拟队列一次遍历；n 为等待队列长度，窗口串行语义下 n 受带宽预算自然限制 |
| 窗口内服务选择（EDF/FCFS） | O(n log n) | 每次窗口开启排序一次，窗口级频率 |
| 应急抢占再检查 | O(n) | 每应急事件一次，应急为低频事件 |

> 数据来源：docs/论文初稿-系统模型章.md（3.5 节）。
