# 「星枢」：通信受限场景下星地协同智能体推理加速系统

> 博士课题方向提案（导师版） · 毛力 · 2026年9月23日
> 说明：本提案所有研究与实验均基于公开数据与自建仿真环境，与工作单位项目彻底切割，不存在保密与职务发明归属问题。

---

## 一、研究背景与问题

随着大模型技术的发展，将智能体（Agent）引入航天器自主任务管理成为趋势（任务规划、异常处置、资源调度）。但卫星场景有两个刚性约束，使地面云计算范式无法直接套用：

1. **星上算力受限**：受功耗、体积、抗辐照要求限制，星上只能部署小参数量模型，复杂推理能力不足；
2. **星地通信受限**：过境窗口有限、带宽窄、延迟大，"遇事问地面"常常来不及。

现状是两头失衡：纯星上小模型处理复杂任务成功率低；纯地面大模型端到端延迟高、依赖链路可用性。**如何在通信窗口约束下动态决策"谁来算"（星上自决 / 等窗送地面 / 星上硬解），并对星上推理进行加速，是一个尚未被系统研究的问题。**

## 二、研究目标

构建一个"星上小模型自主 + 地面大模型兜底"的星地协同智能体系统，研究其核心科学问题：**通信窗口感知的分层推理调度方法**，使系统在任务成功率、端到端延迟、链路占用三者间取得优于任一单点方案的整体最优。

## 三、研究内容

1. **通信窗口感知的星地分层推理调度**（核心）
   - 任务紧急度、链路状态、星上模型置信度三因素联合的调度策略
   - 调度策略的形式化建模与启发式/学习式求解
2. **星载受限算力下的大模型压缩与加速**
   - 领域 LoRA 蒸馏小模型 + AWQ/GPTQ 量化 + 投机解码的组合方法
   - 蒸馏模型同时作为投机解码草稿模型的复用设计
3. **星地协同 Agent 的仿真评测框架**
   - 星座观测任务规划 + 应急重规划场景建模（公开 TLE 数据 + 合成场景）
   - 三基线对比（纯星上 / 纯地面 / 星地协同）与四维度指标（任务成功率 / 端到端延迟 / 链路占用 / 显存功耗）
