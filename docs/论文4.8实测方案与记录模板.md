## 二、实测方案（12 月 AWQ 部分，可直接照做）

### 2.1 实验环境（记录模板见 3-E）

- 硬件：NVIDIA Jetson Orin（记录具体模组：NX 16G / AGX 64G；功耗模式 MAXN 档位）
- 软件：JetPack 版本、CUDA/cuDNN/TensorRT-LLM 版本、lmdeploy/AutoAWQ 版本、vLLM 版本（地面侧对照）
- 地面对照：与星上模型同代的 7B/32B 在 x86 + GPU 上跑 vLLM（记录 GPU 型号）

### 2.2 模型矩阵（3-M 表）

| 模型 | 来源 | 精度 | 用途 |
|---|---|---|---|
| Qwen3-1.7B / 4B（基础模型 A） | HuggingFace 公开权重 | FP16 | 量化前基线 |
| 同上 | AWQ | INT4（w4g128） | M5/M4/M1 主测对象 |
| 同上 | AWQ | INT3（w3g128，如可） | 极限压缩对照 |
| （2027.1）LoRA 蒸馏模型 B | 任务域蒸馏（卫星任务指令集，自建 5k–10k 条） | FP16 → AWQ INT4 | M2/M3/M6 |

### 2.3 测量项与口径定义（每项注明测量方法，口径一经确定不得改）

1. **压缩比** = 量化前权重文件大小 ÷ 量化后权重文件大小；同时记录显存占用（推理常驻，tegrastats 采样峰值与均值）
2. **单 token 解码延迟（TPOT）**：稳态 decode 阶段连续 128 token 的平均间隔，预热 32 token 后开始计时；分输出长度档 {64, 256, 1024}
3. **首 token 延迟（TTFT/prefill）**：输入长度档 {128, 512, 2048, 8192} token，从提交到首 token 返回
4. **端到端任务延迟**：固定 50 条卫星任务 prompt（观测规划/数据筛选/应急重规划三类），星上 AWQ 模型完整回答 vs 地面 32B vLLM 完整回答（不含排队，仅推理）；报均值/P50/P95
5. **功耗**：推理负载全程 tegrastats 1 Hz 采样，报平均功率与能耗/任务（Wh）
6. **量化精度损失**：MMLU 中文子集 + 自建卫星任务评测集（50 题）上的准确率：FP16 vs INT4 vs INT3
7. **（2027.1）置信度分布**：蒸馏模型对 200 条带标任务输出 (答案, 自评置信度)，按任务复杂度 x 分 10 桶记录 (答对率, 平均置信度, 置信度方差) ——直接喂给 M3 拟合

### 2.4 复现纪律（与 v1.2 冻结锚点同标准）

- 随机种子固定；每档配置测 3 遍取中位数
- 原始日志（tegrastats 采样、vLLM 日志、评测脚本输出）归档到 benchmark/results/orin_awq_2026MM/
- 本文件"三、记录模板"填完的版本与 4.8 节成稿同 commit，保证数字可溯源
