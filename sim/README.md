# sim/ —— 星座任务仿真环境

「星枢」的实验数据来源：在地面复现"通信窗口受限 + 星上算力受限"的约束，让三种方案（纯星上 / 纯地面 / 星地协同）在同一场景下可比。

## 当前进度：v0.1 合成场景骨架（2026.9.24）

- ✅ 任务模型（任务 / 紧急度 / 复杂度）
- ✅ 合成通信窗口（周期过境，暂不用 TLE，公开数据后续接入）
- ✅ 两个极端基线：纯地面方案、纯星上方案 + 指标统计
- ⬜ 星地协同方案（核心创新点，11-12 月实现）
- ⬜ TLE 轨道数据接入、应急重规划场景

## 运行

```bash
python sim/main.py
```

输出两个基线在 100 个随机任务下的对比（成功率 / 平均延迟 / 链路占用）。

## 设计说明

- **复杂度阈值**模拟"星上只能处理简单任务"：任务复杂度 ≤ 阈值才允许星上硬解，这是星地协同策略要动态决策的变量
- 随机种子固定，保证每次运行结果可比、实验可复现
